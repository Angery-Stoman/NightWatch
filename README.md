# Nightwatch: 3D Interactive Morse Code Pedagogy

## Overview
Nightwatch is a 3D educational simulation designed to dismantle the steep learning curve of international Morse code. By abandoning traditional behaviorist memorization drills, the application uses constructivist pedagogical theories to ground abstract temporal sequences into tangible, spatial interactions. Users are placed within 3D environments where they must decode volumetric ship signals flashing through fog, tune vintage analog radios to intercept military broadcasts, and lock onto encroaching sonar blips under strict temporal depletion.

The application features an input validation system utilizing a standardized keyboard mapping. This physicalized interaction mirrors the mechanical rhythm of a traditional telegraph key, accelerating the user's transition from conscious visual decoding to reflexive, subconscious translation. By balancing technical instruction with engaging, gamified environmental stressors, Nightwatch transforms an intimidating legacy communication protocol into a highly immersive mechanical challenge, and most importantly, a video game.

## Usage instructions
During active gameplay, position your hands over the keyboard. For inputting Morse code, press the **Spacebar** to input a Morse dash and the **`.` (Period)** key to input a Morse dot. If you input an incorrect character during a module like Iron Sonar, the sequence will instantly reset, forcing you to retype the word from the beginning. To pause the simulation, press the **Escape** key to access the master volume controls or return to the main menu.

## Installation instructions
**Requirements:** * Windows 10/11 OS
* Dedicated GPU (NightWatch is developed to be light on your PC, but I would still recommend a dedicated GPU)
* Standard QWERTY Keyboard
* 1080p or 1440p monitor resolution for optimal UI scaling
